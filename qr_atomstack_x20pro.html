🚀 Cómo publicar en GitHub Pages — Paso a paso
1
Crea una cuenta en GitHub
Ve a github.com y regístrate con tu correo. Es gratuito.
Elige un nombre de usuario — será parte de tu URL final.
2
Crea un repositorio nuevo
Una vez dentro, haz clic en New repository. Nómbralo exactamente:
passport-gmd
Marca la opción Public y haz clic en Create repository.
3
Sube el archivo de la ficha
En la página del repositorio haz clic en uploading an existing file. Arrastra el archivo:
atomstack_x20pro.html
⚠ Importante: renómbralo a index.html antes de subirlo, o GitHub Pages no lo mostrará como página principal.
Tip: Haz clic en Commit changes para guardar.
4
Activa GitHub Pages
Ve a Settings → Pages (menú lateral). En Source selecciona Deploy from a branch, rama main, carpeta / (root). Haz clic en Save.
Espera 1–2 minutos. GitHub te mostrará la URL activa en verde.
5
Tu URL final será
https://TU-USUARIO.github.io/passport-gmd/
Pruébala en el navegador. Debería aparecer la pantalla de login con contraseña.
6
Actualiza el QR con tu URL real
Abre este archivo QR en un editor de texto y cambia la variable:
const QR_URL = 'https://TU-USUARIO.github.io/passport-gmd/';
Guarda, vuelve a abrirlo en el navegador y descarga el PNG actualizado. ¡Listo para pegar en la máquina!
7
Para agregar más máquinas en el futuro
Solo sube un nuevo archivo HTML al mismo repositorio (ej: rotomartillo.html) y crea un nuevo QR apuntando a:
https://TU-USUARIO.github.io/passport-gmd/rotomartillo.html
